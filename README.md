# Домашнее задание №2 — примитивная база данных

> СГЕНЕРИРОВАНО ИИ!(ReadMe и код — с помощью ИИ:D)

Дисциплина: «Программирование на Python», группа М26-555. Решение домашнего задания из спринта 28: процедурное консольное приложение управляет таблицами и хранит данные в JSON-файлах.

## Что реализовано

Создание и удаление таблиц, просмотр списка, добавление, выборка, изменение и удаление записей. Поддерживаются типы `int`, `str` и `bool`, автоматический `ID` и фильтрация по условию. `select` выводит данные через PrettyTable, `info` показывает схему и количество записей.

## Запуск

Нужны `uv` и Python 3.12.10 (версия закреплена в `.python-version`). Из корня этого репозитория:

```powershell
uv sync
uv run database
uv run ruff check .
```

`prompt` используется для ввода команд, `prettytable` — для вывода таблиц. `ruff` — зависимость для разработки. `uv` создаст локальное окружение `.venv`, которое не входит в репозиторий.

Команда `exit` завершает программу, `help` выводит справку.

## Управление таблицами

```text
create_table users name:str age:int active:bool
list_tables
```

Столбец `ID:int` добавляется автоматически. Для удаления таблицы используется `drop_table users`.

## CRUD-операции

После создания таблицы:

```text
insert into users values ("Sergei", 28, true)
insert into users values ("Anna", 21, false)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 2
info users
```

При вставке передаются все значения, кроме `ID`, в порядке объявления столбцов. Строки вводятся в кавычках, логические значения — `true` или `false`. `where` содержит одно равенство, `set` изменяет один столбец. Количество и типы значений проверяются до сохранения.

Команды `delete` и `drop_table` запрашивают подтверждение. Только точный ответ `y` подтверждает удаление; любой другой ответ отменяет операцию.

## Декораторы и кэш

`handle_db_errors` обрабатывает ошибки, `confirm_action` запрашивает подтверждение удаления, `log_time` показывает время выполнения `insert` и `select`. Замыкание `create_cacher` сохраняет результаты одинаковых выборок; после изменения данных старая выборка не используется.

## Хранение данных

Схемы таблиц находятся в `db_meta.json`, записи — в `data/<имя_таблицы>.json`. Эти файлы создаются в текущем каталоге и исключены из Git. Чтобы открыть ту же базу повторно, запускайте программу из той же папки.
